## How to Add New Experiment Results

1. Run new experiments and add to `results.json`:
```json
{
  "model": "claude-3-haiku",
  "challenge": "bug-fix",
  "duration": 45.2,
  "tool_calls": 8,
  "status": "EXCELLENT",
  "exit_code": 0
}
```

2. Regenerate analysis:
```bash
python analyze_efficiency.py
python analyze_anomaly.py
python generate_figures.py
```

3. Update paper statistics manually in:
   - `main.tex` (abstract)
   - `01_intro.tex` (key findings)
   - `04_results.tex` (tables and text)
   - `06_conclusion.tex` (summary)
